# AUTORIZE ACCESS TO NEXUS REPOSITORY
On Nexus Repository Manager
Go to Settings > Security > Realms
Active :
- Local Authenticating for user + password 
- npm Bearer Token for being able to deposit npm repository

# GET A NODEJS APP
git clone https://gitlab.com/twn-devops-bootcamp/latest/05-cloud/cloud-basics-exercises
rm -rf ./cloud-basics-exercises/.git

# SET AN ARTIFACT
cd ./cloud-basics-exercises/app
npm pack
